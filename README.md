> 一个 Windows 本地隐私自查与系统清理工具集：识别远控 / 监控软件、清理导航栏广告入口、管理 MAC 地址。
>
> **全部本地运行，不联网、不上传、不收集任何数据。**

## 功能特性

| 模块 | 说明 | 是否需要管理员 |
|---|---|---|
| 本机扫描 | 只读采集进程 / 服务 / 驱动 / 安装目录，不结束进程、不改注册表 | 否 |
| 明鉴分析 | 内置公开特征库，识别常见远程控制 / 企业管控软件，给出风险与处置建议 | 否 |
| MAC 轮换 | 定时随机化网卡 MAC（保留原厂 OUI），支持局域网扫描 | 是 |
| 导航栏清理 | 一键清理软件往资源管理器塞的网盘 / FTP / 广告入口 | 否 |

**支持识别的主要类别**：零信任/VPN、终端检测响应（EDR）、桌面管控/准入、远程控制、办公通讯监控、电子教室、杀毒套件等，共数十款。

### 方式一：下载单文件（推荐）

从 [Releases](../../releases) 下载 `明鉴隐私工具箱.exe`，**右键 → 以管理员身份运行**。

## 使用说明

### ① 本机扫描

1. 打开工具，进入「① 本机扫描」标签页。
2. 点击「开始只读扫描本机」，等待几秒。
3. 采集内容：进程（含路径）、服务（含可执行路径）、驱动、Program Files / ProgramData 下的安装目录。
4. 点击「把结果送到明鉴分析」自动跳转。

> 这一步**只读**，不联网，不修改任何系统设置。

### ② 明鉴分析

1. 自动填入扫描结果（也可手动粘贴进程 / 服务 / 驱动清单）。
2. 点击「开始分析」。
3. 表格列出命中产品：产品名、厂商、类别、风险星级、状态（已确认/疑似）、置信度。
4. 点选某一行，下方显示：
   - 软件简介
   - 能力清单（远程控制、屏幕截取、键盘记录、开机自启等）
   - 命中了哪些特征
   - 权利说明
   - **个人机怎么处置**
   - **公司机怎么处置**

> ⚠️ 命中只代表"发现与公开规则相符的痕迹"，**不等于软件违法或侵犯隐私**。公司配发电脑上的合规 EDR，与个人电脑被偷装，法律性质完全不同。

### ③ MAC 轮换

1. 进入「③ MAC 轮换」，点击「启动 MAC 轮换器」。
2. 选择网卡，设置轮换间隔，点开始。
3. 它保留网卡原厂 OUI（前 3 字节），只随机后 3 字节。
4. 支持局域网 ARP 扫描、模仿同网段设备类型。

> ⚠️ 每次切换会断网 2~5 秒。在有 MAC 绑定 / 802.1X 认证 / 上网计费的网络中可能掉线。

### 清理导航栏图标

双击 `清理此电脑图标.bat`：

1. 自动扫描三类位置：
   - 此电脑节点（MyComputer\NameSpace）——网盘类
   - 导航栏根（Desktop\NameSpace）——企业版 / 机关版软件塞的入口
   - FTP / 网络位置（FTP\Accounts）——IP 形式的站点
2. 自动保留 Windows 自带的库文件夹（桌面/文档/下载/图片/音乐/视频）。
3. 输入编号选择要删除的第三方项，回车即删。
4. 删完自动重启资源管理器。

> 如果删完还显示，按 F5 刷新或注销重新登录。

## 工作原理

### 导航栏图标是怎么来的

Windows 有一套「命名空间扩展（NameSpace Extension）」机制：软件安装时往注册表写一个 CLSID，就能在"此电脑"或导航栏里凭空显示一个图标，双击其实是拉起它自己的云盘界面或推广页。

常见写入位置：

| 注册表路径 | 对应入口类型 |
|---|---|
| `HKCU\...\Explorer\MyComputer\NameSpace\` | 此电脑节点下的网盘图标 |
| `HKCU\...\Explorer\Desktop\NameSpace\` | 导航栏根的软件入口 |
| `HKCU\Software\Microsoft\FTP\Accounts\` | FTP / 网络位置 |

### 远控软件识别

工具内置公开特征库，收录常见远程控制 / 企业管控软件的进程名、服务名、驱动名、安装路径。分析时把本机采集清单与特征库做匹配，按权重计算风险等级和置信度。

### MAC 轮换原理

修改 Windows NDIS 驱动层的 MAC 覆盖值（写注册表并重启网卡）。此后网卡发出的以太网帧源 MAC 为新值。它**不改网卡出厂硬件 MAC**，重启后可能恢复。

## 常见问题

**Q：exe 报毒 / 杀软拦截？**  
A：PyInstaller 打包的单文件偶尔被误报，加白名单即可；源码可自行审查。

**Q：扫描结果为什么和实际不符？**  
A：工具对残留目录 / 旧安装痕迹也会命中。判断真实风险要看"当前有没有进程 / 服务在跑"。

**Q：删了网盘图标，影响软件本身吗？**  
A：不影响。只是从导航栏隐藏入口，软件照常使用。

**Q：MAC 轮换能完全匿名吗？**  
A：不能。MAC 只在局域网二层可见，出了路由器就是 IP、Cookie、浏览器指纹说了算。
